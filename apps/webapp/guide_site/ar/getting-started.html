🔐تسجيل الدخول والخروج

جديد؟ اضغط Start a free trial في موقع BookPilot، واختر نوع عملك واملأ نموذجاً قصيراً — ثم يساعدك معالج الإعداد على إضافة شعارك وأول منتجاتك والطابعة. لديك حساب؟ استخدم اسم المستخدم وكلمة المرور. يعمل في أي متصفح على الكمبيوتر أو التابلت أو الهاتف، ويمكن تثبيته كتطبيق.

  1. افتح الرابط الخاص بكستظهر صفحة Sign in: “Manage your business — sales, stock, and reports.”
  2. اكتب اسم المستخدم وكلمة المرورثم اضغط Sign in.
  3. نسيت كلمة المرور؟اضغط Forgot password? أسفل زر الدخول واتبع الرابط الذي يصلك بالبريد. إن لم يصل البريد راسلنا وسنعيد ضبطها لك.
نصيحة: في أسفل الشاشة ستجد بريدك الإلكتروني وزر Log out. سجّل الخروج دائماً على الأجهزة المشتركة.
انتبه: بعد عدة محاولات خاطئة ستظهر رسالة “Too many failed attempts. Try again later.” انتظر بضع دقائق ثم حاول مجدداً.

📊لوحتك الرئيسية (Overview)

افتح Overview بعد تسجيل الدخول. إنها الفحص اليومي لصحة عملك.

  • Today’s sales وThis month’s revenue — كيف يسير العمل.
  • Outstanding dues — المبالغ التي لم يدفعها العملاء بعد.
  • Low stock items — المنتجات التي وصلت إلى حد إعادة الطلب.
  • صف Business overview بعدّادات خاصة بنوع عملك (الأعضاء، مواعيد اليوم، الطلبات المعلقة، الدُفعات المنتهية قريباً، المشاريع النشطة…).
  • شريط الاشتراك: Free trial — N days left أو Subscription renews in N days أو Your subscription has expired.
نصيحة: اجعل فتح Overview عادة كل صباح وعند الإغلاق.

🏢إعداد ملف نشاطك التجاري

افعل هذا أولاً — اسمك وعنوانك وشعارك يظهرون على الفواتير.

  1. افتح Settings ← Settings
  2. املأ البياناتName وRegistration number (الرخصة التجارية / السجل التجاري) وAddress وPhone وEmail وDefault currency وارفع Logo.
  3. اضغط Save settingsستظهر “Business settings updated.”
انتبه: اختر العملة الصحيحة الآن، فهي تُستخدم في الفواتير والتقارير.

👥العملاء

كل من يشتري منك — أو يحجز لديك — هو عميل.

  1. افتح People ← Customers ← + Add customer
  2. أدخل Name وPhone وEmail وAddressالاسم وحده يكفي عملياً. رقم الهاتف يساعدك على إيجاده بسرعة.
  3. احفظاستخدم Edit لتصحيح البيانات في أي وقت. Export CSV يحمّل القائمة.
جدير بالمعرفة: يوجد Walk-in Customer مدمج يُستخدم عند البيع لشخص دون إنشاء سجل له.
انتبه: لا يمكن حذف عميل لديه مبيعات أو مواعيد أو سجلات أخرى — هذا يحمي حساباتك. عدّل بياناته بدلاً من ذلك.

📦المنتجات والفئات والعلامات والوحدات

للمتاجر: كل ما تبيعه هو منتج. جهّز القوائم الصغيرة أولاً ثم المنتجات.

  1. Unitsافتح Units وأضف طريقة عدّ المخزون: pcs, kg, box, meter, litre.
  2. Categories وBrandsافتح Categories وBrands لتجميع المنتجات (اختياري لكنه مفيد جداً للبحث والتقارير).
  3. أضف منتجاًProducts ← + Add product. املأ SKU وName وCategory وBrand وUnit وCost price وSelling price وReorder level.
  4. Extra detailsسطر لكل تفصيل، مثل Colour: Blue أو Size: L.
  5. Variantsاضغط + Variant على المنتج لإنشاء خيارات اللون/المقاس، لكل منها SKU وسعر خاص.
  6. Barcodesاضغط Barcode على المنتج، أو افتح Print Barcodes لطباعة عدة ملصقات دفعة واحدة.
نصيحة: SKU هو رمز المنتج الخاص بك — قصير وفريد مثل SHIRT-BL-L، ولا يتكرر أبداً.
انتبه: لا يمكن حذف منتج له مبيعات أو حركات مخزون. عدّله بدلاً من ذلك.

📥الاستيراد والتصدير عبر Excel (CSV)

أضف مئات المنتجات دفعة واحدة، أو نزّل قائمتك وعدّلها في Excel.

  1. افتح Products واضغط Import CSV
  2. جهّز الملفيجب أن يحتوي الصف الأول على هذه العناوين: SKU, Name, Unit, Selling Price (إلزامية) واختيارياً Category, Brand, Cost Price, Reorder Level.
  3. ارفع الملفستظهر “Imported N new products, updated N existing.” الصفوف الخاطئة تُتجاوز وتُعرض لتصححها.
SKUNameUnitSelling PriceCategoryBrandCost PriceReorder Level

نصيحة: نفس الـ SKU مرة أخرى = تحديث وليس تكراراً. الفئات والعلامات والوحدات غير الموجودة تُنشأ تلقائياً.
جدير بالمعرفة: احفظ ملف Excel بصيغة CSV (UTF-8). استخدم Export CSV للحصول على قالب جاهز بمنتجاتك الحالية.

🧾نقطة البيع POS — الفوترة عند الكاشير

أسرع طريقة للبيع. افتح [[[Sales]]] ← [[POS]].

  1. ابحث عن المنتجاكتب الاسم أو الـ SKU في مربع البحث (أو امسح الباركود) ثم اضغط على المنتج. غيّر الكمية في السلة عند الحاجة.
  2. الفرع والعميلاختر Branch إن كانت لديك فروع. اترك Walk-in Customer أو اختر عميلاً محفوظاً.
  3. الكوبون (اختياري)اكتب Coupon code. يظهر الخصم قبل الدفع.
  4. طريقة الدفعاختر Cash أو Card أو Bank Transfer.
  5. اضغط Complete Saleستظهر “Sale complete — INV-000123” مع رابط Print receipt. ينخفض المخزون وتتحدث الحسابات فوراً.
نصيحة: العملاء المحفوظون يكسبون نقاط ولاء تلقائياً على مبيعات POS.
انتبه: إذا ظهرت رسالة حمراء (مثل Cart is empty أو مشكلة مخزون) فلم يُحفظ شيء — صحّح ثم اضغط Complete Sale مجدداً.

↩️المرتجعات والاسترداد

أعاد العميل بضاعة؟ لا تحذف الفاتورة أبداً — نفّذ مرتجعاً ليبقى المخزون والحسابات صحيحين.

  1. افتح Sales ← Returns & Refunds ← + New return
  2. أدخل رقم الفاتورةمثل INV-000123، ثم اضغط Find invoice.
  3. أدخل Return qty لكل صنفتعرض الشاشة الكمية المباعة وما أُرجع سابقاً.
  4. اختر طريقة الاستردادReason وRefund method (Cash أو Card أو Bank أو Store Credit) وDate. اضغط Process return.
  5. انتهى الأمر“Return processed and stock updated.” تعرض قائمة المرتجعات وتقريرها الإجمالي وأهم الأسباب.
انتبه: لا يمكنك إرجاع أكثر مما بِيع. وإن أُرجعت الفاتورة بالكامل فستظهر رسالة بذلك.

🎁الكوبونات ونقاط الولاء

كافئ عملاءك ونفّذ العروض.

الكوبونات

  1. افتح Sales ← Coupons ← + Add coupon
  2. املأ بيانات الكوبونCode (مثل EID10) وDiscount type (Percentage أو Fixed Amount) وDiscount value وMin purchase وMax discount وStart date وExpiry date وUsage limit.
  3. التفعيل والإيقافاستخدم Activate / Deactivate بجانب أي كوبون.
  4. الاستخداماكتب الرمز في شاشة POS.

نقاط الولاء

العملاء المحفوظون يكسبون النقاط تلقائياً عند الدفع — افتراضياً نقطة واحدة لكل 10 يُنفقها العميل. افتح [[[Sales]]] ← [[Loyalty]] لرؤية الأرصدة، واضغط [[Redeem points]] لاستخدام النقاط (customer, points, reason).

جدير بالمعرفة: لا تُمنح نقاط على مبيعات Walk-in لعدم وجود عميل. إن أردت معدلاً مختلفاً فاطلب منا ذلك.

🚚الموردون والمشتريات

سجّل المخزون الذي تشتريه والمبالغ التي عليك.

  1. أضف مورداًPurchases ← Suppliers ← + Add supplier (الاسم والهاتف والبريد والعنوان).
  2. سجّل عملية شراءPurchases ← + New purchase. اختر Supplier وProduct وBranch/Warehouse وأدخل Quantity وUnit cost وBill number وDate. ستظهر “Purchase recorded and stock updated.”
  3. ادفع للموردSuppliers ← اضغط اسم المورد ← + Record payment. أدخل Amount وDate وMethod (Cash/Bank) واختيارياً الفاتورة المقصودة.
  4. راجع الإجمالياتافتح Purchase Reports: إجمالي المشتريات والمدفوع والمتبقي والإجمالي لكل مورد.
نصيحة: سجّل رقم فاتورة المورد — يسهّل مطابقة كشوف الحساب.

💸المصروفات

الإيجار والرواتب والكهرباء والنقل — سجّل كل تكلفة ليكون ربحك حقيقياً.

  1. أضف الفئات مرة واحدةFinance ← Expenses ← Categories. اضغط + Add common categories (Rent, Salary, etc.) لإضافة الفئات المعتادة فوراً، أو + Add category لفئتك الخاصة.
  2. سجّل مصروفاً+ Add expense ← اختر Category وDate وAmount وDescription وPayment method (Cash أو Bank). ستظهر “Expense recorded.”
  3. راجعافتح تقرير المصروفات من صفحة Expenses لرؤية إجمالي المصروفات وإجمالي كل فئة.
جدير بالمعرفة: كل مصروف يُرحَّل تلقائياً إلى حساباتك.

🛡️الفريق والأدوار (حسابات الموظفين)

امنح كل موظف حسابه الخاص، وحدّد ما يمكن لكل شخص رؤيته وفعله.

الدورالغرض منه
Ownerوصول كامل — التقارير والأدوار والفريق والفواتير
Accountantالمحاسبة والمبيعات والمشتريات والمصروفات والبنوك والرواتب
Staffالعمل اليومي: إنشاء الفواتير وإدارة المخزون والعملاء
  1. أضف حساباًPeople ← Team ← + Add team member. أدخل Username وEmail وPassword (8 أحرف على الأقل) واختر Role. ستظهر “… added as Staff.”
  2. غيّر دوراً أو أزل شخصاًفي صفحة Team استخدم Change role أو Remove. لا يمكنك إزالة نفسك.
  3. أنشئ دوراً مخصصاً (مثل Cashier)Manage roles ← + Create custom role ← اكتب الاسم ← Edit permissions وحدّد بالضبط ما يُسمح له ← Save permissions.
جدير بالمعرفة: لباقتك حد أقصى لعدد المستخدمين. إذا بلغته فاطلب منا الترقية.
Staff داخل قسم عملك (مثل Spa أو Saloon) شيء مختلف: هي قائمة الأشخاص الذين ينفذون العمل (المعالجون والمصففون) ولا يحتاجون إلى حساب دخول.
انتبه: الأدوار الثلاثة الأساسية (Owner وAccountant وStaff) لا يمكن تعديلها — أنشئ دوراً مخصصاً بدلاً منها.

🏬الفروع والمخزون حسب الفرع

لديك أكثر من متجر أو مستودع؟ احتفظ بمخزون كل فرع منفصلاً.

  1. أضف فرعاًBusiness ← Branches ← + Add branch. أدخل Name وAddress وPhone وManager name وحدّد Is default للفرع الرئيسي.
  2. بِع واشترِ حسب الفرعاختر الفرع في POS وفي Purchases.
  3. قارن المخزوناضغط Stock by branch لرؤية مخزون كل منتج في كل فرع والإجمالي.
انتبه: لا يمكنك حذف فرعك الوحيد، ولا فرعاً لديه سجلات.

💳اشتراكك والفواتير

يمكن لـ Owner فقط الدفع أو تقديم دفعة.

  1. اطّلع على باقتكFinance ← Billing: الباقة الحالية والسعر وعدد المستخدمين المسموح والأيام المتبقية وسجل الدفعات.
  2. ادفع بالبطاقةاضغط Pay now وادفع بالبطاقة أو Apple Pay أو Google Pay في صفحة الدفع الآمنة. يتحدث اشتراكك تلقائياً.
  3. دفعت بتحويل بنكي أو نقداً؟املأ Amount وMethod وReference وNotes ثم اضغط Submit payment. نؤكدها ونجدد اشتراكك.
  4. الفترة التجريبية والانتهاءخلال الفترة التجريبية تعرض اللوحة الأيام المتبقية. بعد الانتهاء قدّم دفعة للاستمرار.
جدير بالمعرفة: الدفع بالبطاقة متاح فقط في الدول التي جرى إعداده فيها. وإلا فاستخدم التحويل البنكي وقدّم المرجع.

🔔الإشعارات

جرس عملك — افتح [[[Settings]]] ← [[Notifications]].

  • Low stock عندما يصل منتج إلى حد إعادة الطلب.
  • Overdue invoices — الفواتير المتأخرة غير المدفوعة.
  • Subscription — اقتراب انتهاء الاشتراك أو انتهاؤه.
  • دفعات الأدوية / المكملات التي يقترب انتهاؤها (الصيدلية ومتجر البروتين).

اضغط [[Mark all as read]] لمسحها.
